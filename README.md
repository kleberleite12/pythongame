# Futebol Flappy — Jogo 2D em Python

Jogo estilo *endless runner* com temática de futebol, desenvolvido em Python com a biblioteca Pygame.

## Funcionalidades

- Game loop com controle de frames e atualização contínua de estados
- Física de movimento: gravidade, impulso de pulo e resposta ao teclado
- Geração dinâmica de obstáculos e detecção de colisão
- Sistema de pontuação com recorde persistido em arquivo (mantido entre execuções)
- Telas de menu inicial e game over, com transição entre estados
- Trilha sonora, efeitos sonoros e sprites customizados

## Tecnologias

- Python 3
- Pygame

## Como executar

```bash
pip install pygame
python main.py
```

## Controles

- **Espaço** — pular
- **Esc** — sair
